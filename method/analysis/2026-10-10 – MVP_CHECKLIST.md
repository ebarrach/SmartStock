## 1. Smart Cabinet

### Identification and Stock Management

- [ ] Identify a product or batch using DataMatrix
- [ ] Detect a weight variation
- [ ] Detect the addition of a product
- [ ] Detect the removal of a product
- [ ] Automatically update the stock quantity
- [ ] Preserve stock data after a system restart
- [ ] Store product information (name, batch number, expiry date)
- [ ] Set a minimum stock level for each product
- [ ] Alert the user when stock is running low
- [ ] Detect discrepancies between measured and recorded stock
- [ ] Record the expiry date of each batch
- [ ] Alert the user when a product is approaching its expiry date
- [ ] Monitor the temperature inside the cabinet
- [ ] Monitor the humidity inside the cabinet
- [ ] Alert the user when temperature or humidity exceeds configured limits
- [ ] Record temperature and humidity history


### Sensors

- [ ] Measure temperature
- [ ] Measure humidity
- [ ] Detect movement using the IR sensor
- [ ] Detect sensor failures
- [ ] Transmit sensor measurements to the Raspberry Pi
- [ ] Camera
- [ ] LEDs

### Communication

- [ ] Connect the cabinet to the Wi-Fi network
- [ ] Transmit the required information to the application
- [ ] Receive the required information from the application
