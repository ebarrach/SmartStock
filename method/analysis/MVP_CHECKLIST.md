# SmartStock — MVP Checklist

> Task: SS-001.2 — Define the MVP Criteria for the Smart Cabinet and Emergency Bag  
> Status: In Progress  
> Sprint: S1 — Scoping

## 1. Smart Cabinet

### Identification and Stock Management

- [ ] Identify a product or batch using DataMatrix
- [ ] Detect a weight variation
- [ ] Detect the addition of a product
- [ ] Detect the removal of a product
- [ ] Automatically update the stock quantity
- [ ] Preserve stock data after a system restart

### Sensors

- [ ] Measure temperature
- [ ] Measure humidity
- [ ] Detect movement using the IR sensor
- [ ] Detect sensor failures
- [ ] Transmit sensor measurements to the Raspberry Pi

### Communication

- [ ] Connect the cabinet to the Wi-Fi network
- [ ] Transmit the required information to the application
- [ ] Receive the required information from the application

---

## 2. Emergency Bag

- [ ] Enable tracking of products stored in the emergency bag
- [ ] Communicate via Bluetooth
- [ ] Communicate with the doctor's application
- [ ] Transmit the required information to SmartStock

## 3. Application

- [ ] Display the current stock
- [ ] Display product information
- [ ] Display environmental measurements
- [ ] Display alerts
- [ ] Display the history of product additions and removals
- [ ] Refresh information after an operation

## 4. Scala / Akka Agent

- [ ] Receive events generated by the system
- [ ] Process sensor events
