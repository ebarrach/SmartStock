## 1. Smart Cabinet

### Identification and Stock Management

- [x] Identify a product or batch using DataMatrix
- [x] Detect a weight variation
- [x] Detect the addition of a product
- [x] Detect the removal of a product
- [x] Automatically update the stock quantity
- [x] Preserve stock data after a system restart
- [x] Store product information (name, batch number, expiry date)
- [x] Set a minimum stock level for each product
- [x] Alert the user when stock is running low
- [x] Detect discrepancies between measured and recorded stock

- [x] Monitor the temperature inside the cabinet
